🔔 아이폰 네이티브 알림 (.ics 캘린더)

웹앱을 꺼놔도 아이폰 잠금화면에 10분 전 푸시 알림이 정확히 울리도록, 현재 내 시간표(매주 반복) + 12월 시험일정 + 수행평가 마감일을 표준 캘린더 파일(.ics)로 만들어 드립니다.

📌 아이폰 캘린더 적용 3단계

1. 위 다운로드 버튼을 눌러 final_schedule.ics 저장

2. Safari 다운로드 목록 또는 「파일」 앱에서 해당 파일을 터치

3. 우측 상단 「모두 추가」를 누르면 10분 전 잠금화면 알림 자동 등록 끝!

🔒 잠금화면 · 홈화면 라이브 위젯 (Scriptable)

아이폰 잠금화면(시계 위 한 줄 / 시계 아래 사각형)과 홈화면에서 멈추지 않고 자동 갱신되는 네이티브 위젯입니다. 아래 코드에는 지금 수정하신 내 시간표가 자동 반영되어 있습니다.

📌 잠금화면 위젯 설치법 (무료 앱 Scriptable)

1. App Store에서 무료 앱 「Scriptable」 설치 후 우측 상단 + 버튼 터치

2. 복사한 코드를 그대로 붙여넣고 이름을 기말플래너로 저장

3. 아이폰 잠금화면 길게 누르기 → 사용자화 → 위젯 추가 → Scriptable 선택 후 방금 만든 스크립트 지정!

🏝️ 다이내믹 아일랜드 카운트다운

Apple 보안 정책상 Safari 웹앱은 다이내믹 아일랜드(Live Activities)를 직접 제어할 수 없습니다. 대신 아이폰 기본 「단축어」 앱과 연결하면 버튼 한 번으로 현재 공부 블록 남은 시간만큼 기본 타이머가 실행되어 다이내믹 아일랜드 & 잠금화면에 실시간 카운트다운이 뜹니다!

현재 자동 계산된 타이머 시간
현재 과목 기준 25분

📌 30초 최초 1회 단축어 만들기

1. 아이폰 기본 「단축어」 앱 열기 → 우측 상단 + 버튼

2. 동작 추가 검색: 「타이머 시작」 선택

3. 시간 숫자 부분을 길게 눌러 「단축어 입력」으로 변경, 단위는 「분」으로 설정

4. 단축어 이름을 정확히 공부타이머 로 저장 완료!

이제 위 [🏝️ 타이머 실행] 버튼을 누르면 다이내믹 아일랜드에 남은 공부 시간이 실시간으로 뜹니다.
